# 候选反应事件工作台第一版

日期：2026-10-27。目标为读取 bonds 文件，审查相邻保存帧之间的候选拓扑反应。
本轮已实现事件浏览、前后连接图、原子去向、筛选分页和导出，不需要先指定目标物种。

## 运行

在当前已安装 Python/FastAPI/uvicorn 的环境中：

```powershell
cd D:\smiletosvg
$env:PYTHONPATH='D:\smiletosvg;D:\smiletosvg\web'
python -m uvicorn app.main:app --host 127.0.0.1 --port 8765
```

浏览器访问 http://127.0.0.1:8765 。服务仅监听本机。
也可按 web/README.md 安装后运行 smiletosvg-web（默认端口 8000）。

提交本机 bonds 文件路径，填写正确元素映射与 ps/step。保存帧间隔可显式指定，
留空时由前两个保存帧推定；这不能识别最开始的缺帧或始终等间隔抽帧。
往返窗口默认 0，关闭往返标记。无论是否标记，原始事件都保留在事件页和输出中。

仓库小例子：examples/ch4_dissociation.bonds，映射 1:C,2:H，帧间隔 10，
时间换算 0.001 ps/step。该例子为人工数据，不代表真实体系验证。

## 已实现的行为

1. 继续直接使用文件邻接，不施加二次 BO 阈值或价态删边。持久帧检查器统一校验
   原子总数、ID/类型、双向邻接与 BO、帧间隔；损坏帧和缺口停止分析。
2. 对前后完整分子建立原子重叠关系，按关联分量组织事件。没有邻接边变化时不产生
   事件；同分子式的内部连接变化仍可报告。无关分子的变化分别形成独立事件。
3. 每个事件核对两侧原子多重集与元素组成，保存完整前后分子、时间区间、断成边和原子 ID。
4. 结构先按指纹分桶，再做精确图同构核对。给出运行内稳定编号，如 C2H6O-001。
   同构检查预算耗尽时保守拆分，可能多出类别；编号不保证跨运行相同。
5. SQLite 保存最终事件证据及往返状态。事件列表只读取摘要字段，详情按需读取完整记录。
6. 事件页显示全部原始事件，支持分页、分子式、搜索和时间区间筛选；不显示事件状态分类。
   分子式是参与完整分子的组成匹配，元素书写顺序不影响结果。
7. 点击事件行的编号、帧间隔或反应式后同步显示对应前后分子；加载期间清空旧详情，
   快速切换时仅显示最后选中的事件。消失边用虚线、新增边用实线强调。点击原子编号，
   两侧同号原子同步高亮并显示所属结构变化。另提供原子去向表。
8. 大分子显示变化位置附近的局部拓扑，最多 40 原子，明确显示局部/完整原子数。
   变化位置过多时可能仅展示部分中心；单侧分子卡片最多 24 个，原子表最多 250 行，
   断成边文本最多 80 条。全部证据始终保存在事件 JSON 中，可导出。
9. 每条事件可导出 JSON；输出页可下载完整 CSV、汇总网络 JSON、事件 SQLite 和任务记录。
   任务 URL 带 job 参数，刷新后恢复结果。旧任务没有事件索引时提示重新分析。
10. 现有物种表和汇总网络保留为辅助页，按需加载。物种预览有 500 行上限并明确提示；
    汇总网络展示前 18 个高频反应的全部参与结构，不能代替逐次事件证据。

## 结果和接口

| 输出 | 用途 |
| --- | --- |
| reaction_events.csv | 所有原始候选事件，包含 accepted/filter_reason/filter_group |
| molecule_registry.csv | 结构编号、分子式、内部键、代表原子及标识状态 |
| species_timeseries.csv | 各帧结构数量，包含结构编号 |
| reaction_network.json | 按未标记往返事件聚合的统计及帧间隔元数据 |
| event_index.sqlite | 事件摘要、完整证据及分子式/内部结构键索引 |
| 任务记录 JSON | Web 任务参数、处理统计、状态和输出路径 |

```text
GET /api/jobs/{job}/events
    ?offset=0&limit=50&q=&formula=&species_key=&start_step=&end_step=&status=all
GET /api/jobs/{job}/events/{event}
GET /api/jobs/{job}/events/{event}/export
```

status 可为 all、accepted（未标记往返）、recrossing（往返候选）。时间范围筛选
采用候选事件区间与查询区间相交。列表包含精确 total、offset、limit、has_more。
详情 reaction 用结构编号表示并合并系数；reaction_identifiers 保留辅助标识表示。
CSV 的原 reaction 列保持兼容；可通过 event_id 与 SQLite 详情关联。

## 化学表示的边界

图示为连接拓扑，不代表真实坐标或已经确认的化学键型。事件定位于两个保存帧之间，
可能合并期间发生的多个过程。同一分子内的并发变化先作为一个关联候选事件。
仅键级/电子状态变化但邻接不变的过程，目前不产生事件。

本轮仍以 RDKit 生成辅助标识；Open Babel 未新增。删除旧标识接口的失败后全单键回退，
标识失败保留拓扑事件；缓存区分用于表示的键级布局。由连续 BO 离散构造的旧标识仍为
best-effort，不代表唯一化学身份；新的 CHO 候选推断入口仍可独立运行。
同一拓扑的不同电子解释不会被当成多个独立观测分子。

精确分页、单事件导出及旧/损坏索引。列表分页不会解码完整大型证据 payload。

同号原子高亮、单事件下载、空结果、无变化任务、重复 timestep 失败和 390 px 窄屏通过。
启用 0.02 ps 往返窗口的同一人工例子保留 138 原始事件，标记其中 136 条。

每帧 10330 原子，映射 1:H,2:C,3:O，关闭标识生成与往返标记：

- 256 个候选事件，221 个聚合反应，265 个连接结构类别。
- 独立从原始邻接重建分量并核对 19 个帧间隔：339 条消失边、268 条新增边恰好覆盖一次。
- 256 个事件的两侧原子守恒；646 条参与分子证据与原始分组、元素和连接一致。
- 256 条 CSV 与 SQLite 的状态和标记一致。

真实核对记录：outputs/event_browser_real_20261027/verification.json。
这是有限真实片段的软件验证，尚未运行全轨迹，也没有完成真实体系往返参数校准或峰值内存测量。
