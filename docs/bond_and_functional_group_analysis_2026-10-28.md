# 键与官能团候选的逐帧数量分析

新增“键分析”和“官能团分析”两个结果页，横轴为真实保存帧时间，纵轴为数量。数据先写入 CSV，折线图只读取统计结果，不修改原始计数。

## 键数量口径

连接直接采用 bonds 文件的邻接表，同一无向原子对在每帧只计一次。C–C、C–H、C–O、O–H、H–H、O–O 不区分单、双或三键；其他元素映射可增加对应元素对分类。

逐帧分别输出现存数量、相对前帧的新增数量和消失数量。第一个保存帧没有前帧，差分留空，图中不补零。每个元素对满足：

`本帧现存数 = 前帧现存数 + 新增数 - 消失数`。

## 官能团候选口径

规则版本为 `cho-local-topology-candidates-1`。这是基于局部文件连接的候选匹配，不推断化学键级、形式电荷或自由基电子，也不先生成 SMILES/InChI。

| 候选 | 局部匹配概要 |
| --- | --- |
| 羟基 | O 恰好连接一个 C 和一个 H，H 为终端；排除已经归入羧基的 OH |
| 醚 | O 恰好连接两个 C；排除已经归入酯基的桥接 O |
| 醛基 | C 恰好有三个邻居：一个终端 O，另外两个为 C/H 且至少一个为 H |
| 酮型羰基 | C 恰好连接一个终端 O 和两个 C；不代表全部 C=O |
| 羧基 | C 恰好连接两个 O 和一个 C/H，其中一个 O 为终端，另一个 O 恰好再连接 H |
| 酯基 | C 恰好连接两个 O 和一个 C/H，其中一个 O 为终端，另一个 O 恰好再连接另一 C |

羧基、酯基先匹配，避免其 OH/O 再计入普通羟基和醚。水、孤立 OH、CO 和 CO₂ 不匹配上述有机候选。

H、C、O 的局部配位规则分别为 1、4、2；涉及超过规则配位的局部环境不计候选，但所有原始连接仍计入键数量，不据此删边或重划分子。非 CHO 元素和超配位观测数在元数据 coverage 中列出。未匹配的 O 还包括水、气体和其他局部环境，不能直接解释成识别失败。

每类同时提供“候选个数”和“含候选的分子数”。同一帧一个分子含两个羟基候选时，分别贡献 2 和 1。零表示本规则没有匹配，不能证明某种真实化学官能团不存在。

## 输出

| 文件 | 内容 |
| --- | --- |
| bond_counts.csv | 各帧总连接数及元素对连接数 |
| bond_changes.csv | 各帧相对前帧的新增/消失连接数 |
| functional_groups.csv | 各类官能团拓扑候选个数 |
| functional_group_molecules.csv | 含各类候选的分子数 |
| count_analysis.json | 规则、帧范围、元素映射、时间换算、源文件 stat、覆盖统计与完成状态 |

新分析在已有逐帧读取中复用校验后的分量，同时输出这些结果。旧任务可在计数页单独补算；补算以原任务记录的帧数为上限，不重新执行结构同构或反应分析。输入路径只取自已保存任务记录，不能从补算请求另传路径；若原始文件 stat 不符、帧数不符或输入校验失败，则保留原反应结果并报告补算失败。

## 页面与导出

- 每图可选最多四类曲线，所有六类均可切换，完整数据始终保留在 CSV。
- 可以限制显示时间范围，逐帧查看原始数值，切换现存/新增/消失或候选数/含候选分子数。
- 现存连接数默认原始线；官能团和连接差分默认显示浅色原始线与 5 ps 居中移动平均，窗口可设为 0。时间缩放不改变均值所用邻域，原始 CSV 不受影响。
- 超过 API 点数上限时，保留全时间范围首尾与分桶极值，并标明抽样；抽样图禁用平滑，完整数据从 CSV 下载。
- 图按 Times New Roman、莫奈绿色系、左下内向刻度绘制，可导出 SVG 或 1200×800、300 DPI PNG。图内不放总标题。

接口：`GET /api/jobs/{job}/counts?kind=bonds|functional&metric=count|formed|broken|molecules`；`POST /api/jobs/{job}/counts` 对已完成任务单独补算。主反应任务在补算期间仍保持完成状态，事件可继续查看。
