# 反应分析性能优化与结果等价验证

本次只优化已有分析流程的重复计算，不改变文件连接、分子划分、结构去重、反应事件或往返标记的判定规则。

## 源码修改

- `reaxnet/parser.py`：逐邻居检查原子 ID 是否存在，避免对每个原子重复遍历整帧 ID。保留完整的缺失邻居集合和原有报错内容。
- `reaxnet/chemistry.py`：复用 `ConnectivityTracker` 已校验并划分的分子及其连接，避免重复求连通分量和为每个分子扫描全帧连接。
- 每个分子的键级签名只计算一次，仍保留原有输出字段和半步离散表示。
- 关闭标识生成时直接使用同样的不可变 disabled 结果，跳过标识缓存键和标识调用；开启标识时保留原来的缓存键与 BO 区分。

仍使用原有的 `T{timestep}:M{index}` 实例编号，结构注册顺序、分子式计算、连续 BO、原子 ID、守恒检查和输出格式均保留。
