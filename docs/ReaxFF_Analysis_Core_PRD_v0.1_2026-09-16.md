# ReaxFF 反应分析内核产品需求文档

版本 v0.1　日期 2026年9月16日　项目 smiletosvg

## 01 产品目标与范围

本项目面向个人科研人员的本地 ReaxFF 轨迹分析。产品目标是从模拟中的原子连接及其变化出发，识别分子和化学物种、统计关键产物、追踪反应事件，并生成可回查原始轨迹的反应网络和产物路径。SMILES 与 InChI 应参与结构识别、物种归并和目标匹配，而不是仅作为导出字段。

本 PRD 定义分析内核的需求和拟采用的实现方式，为后续算法验证与开发提供依据。文中“应”表示目标要求；不表示当前代码已经实现或已通过真实数据验证。

### 决策状态

| 状态 | 含义 |
| --- | --- |
| 已明确范围 | 本地科研使用，先讨论和实现分析内核，前后端后续再议 |
| 拟定方案 | 根据本轮讨论整理的处理流程、数据模型和输出约定，进入验证后可修订 |
| 待验证参数 | 连接阈值、电子状态推断、时间过滤窗口等，不能把演示数值当作正式默认值 |

### 核心工作流

输入与核查 → 连接判定 → 分子实例识别 → 化学结构推断与物种归并 → 关键产物匹配 → 候选事件识别 → 事件标记与筛选 → 反应网络与路径 → 数据及 SVG 导出。

### 本期范围

- 以 bonds 为主要数据源，支持配套坐标与分析配置；逐帧处理并保留原子追踪依据。
- 支持分子图、结构候选、物种注册、关键产物匹配、反应事件和路径分析。
- 保留结构歧义、转换失败和过滤原因，使汇总结果可审计、可复现。
- 提供数据导出和基于事件证据的路径 SVG；复杂可视化交互后续设计。

### 暂不纳入

前端页面、后端 API、账号、多租户、云端部署和计费不在本期讨论范围。速率常数、Arrhenius 拟合、QM 任务及能垒计算不列入当前核心需求。分子寿命、产率和选择性须另行定义后扩展。

### 成功标准

每个物种统计值应能追溯到分子识别记录，每条反应汇总应能追溯到具体事件，每条观察路径应满足时间顺序和原子对应关系。程序不得把结构规则检查通过等同于科学正确性，也不得把网络中可连通的路线冒充轨迹中观察到的路径。

## 02 输入约定与已核查数据

### F01 输入与一致性检查

基础输入为 bonds 文件和原子类型到元素的映射。涉及 ps、过滤时窗等物理时间时，必须提供步长、单位及必要的时间段信息；缺少这些信息时只允许按 timestep 工作。

坐标轨迹为增强输入，用于几何核查、原子空间结构及回放。仅做连接、分子数量和原子映射分析时，不应强制要求坐标文件。

| 输入 | 要求与用途 |
| --- | --- |
| ReaxFF bonds | 原子 ID、类型、邻接原子、逐键 BO 和 timestep；保留原始字段及文件定位信息 |
| 元素映射 | 显式提供或从配套脚本提取；禁止默认把类型 1、2、3 当作固定元素顺序 |
| 时间配置 | 单位、积分步长、分段或重置说明；不得把输出间隔误当积分步长 |
| 坐标轨迹 | 按 timestep 与原子 ID 对齐；支持声明的坐标类型、盒子与周期边界 |
| 可选辅助文件 | 输入脚本、species、log、初始 data；用于提取配置、交叉核查或关联状态量 |

力场和 restart 文件不作为常规后处理的强制输入。species 不是重建分子图的必要来源；与其比较时，应先对齐阈值、输出时间和键级平均方式。[1][2]

### 异常处理

检测重复原子、缺失映射、时间倒退、重复帧、损坏或截断帧、未声明的原子增删。错误帧不得静默当作空体系。跨损坏帧不自动生成反应；分段或缺帧时标记时间缺口。坐标缺失只关闭对应几何能力，不凭行号错配数据。

## 03 从连续键级到分子连接

### F02 键数据读取

bonds 中的 bo_1 至 bo_nb 是与邻接原子一一对应的 ReaxFF 连续 bond order；abo 为原子总键级，不代替某一对原子的 BO。连续 BO 不等于结构式中的单键、双键和三键。[1]

同一原子对用排序后的两个原子 ID 作为键。双向记录需核查一致性，允许的数值差异和合并方式列入配置。保留原始值，禁止无诊断地覆盖冲突。缺失记录与精确 BO 为零必须区分。

### F03 连接状态判定

基础比较方案为单阈值：BO 大于连接阈值时建立连接，否则不连接。LAMMPS species 的默认 cutoff 为 0.3，可按原子类型对配置；它是比较基线，不是已为本项目验证的最优参数。[2]

拟定增强方案为成断键双阈值，成键阈值应大于断键阈值。对正常且完整的保存帧，更新规则如下。

| 上一帧状态 | 当前条件 | 新状态 |
| --- | --- | --- |
| 不连接 | BO ≥ 成键阈值 | 连接 |
| 不连接 | 未达到成键阈值 | 不连接 |
| 已连接 | BO ≤ 断键阈值 | 不连接 |
| 已连接 | 尚未降到断键阈值 | 保持连接 |

初始帧必须显式规定初始化阈值；拟用成键阈值初始化并记录策略。成键 0.50、断键 0.35 仅为讨论示例，不作为正式默认参数。

当完整文件因输出截断而没有某原子对记录时，可以利用已知截断界限推理；不能声称读到了 BO＝0。断键阈值若低于可观察的输出下限，该区域无法可靠判定，应拒绝此配置或进入显式不确定状态。帧损坏与正常截断缺失必须分开处理。

按 C—C、C—H、C—O、O—H 等元素对比较候选阈值，核查敏感结构、BO 与几何变化。不得为得到预期关键产物而单独放宽其判据。是否增加持续时间确认，需评估与后续往返过滤的叠加影响。

### F04 分子实例识别

原子作为节点、接受的连接作为边，利用连通分量识别每帧分子；孤立原子保留。分子实例记录帧、原子集合、分子式、连接图、原始 BO 和诊断信息。

分子实例是某一帧的一组具体原子；化学物种是按结构规则归并的类别。实例 ID 应带帧或唯一记录标识，不把逐帧重新编号当作持续身份。跨帧追踪由原子对应关系完成。

## 04 化学键类型与电子状态推断

### F05 联合结构推断

固定已接受的连接和实际原子组成，再联合推断单键、双键、三键、形式电荷与自由基状态。不得将 ReaxFF BO 直接四舍五入作为最终化学键类型，也不得为满足价态补入未观察到的氢。

拟定方法为约束候选搜索：先给连接分配基础单键；在所声明的元素价态和电子状态模型下，提高部分键的类型并检查整个分子的约束。存在多个有效组合时保留候选，结合 BO、局部几何及相邻帧证据排序。具体搜索器、代价函数和接受阈值待验证。[3][4]

### 双键判定示例

对于碳连接两个 H 和一个 O 的 CH2O，在中性闭壳层假设下，两条 C—H 各为单键。C—O 设为单键时不能满足该假设下的 C 和 O 价态，设为双键时两端同时满足，得到甲醛候选。该结论依赖连接与电子状态假设，不能外推为所有 C—O 的通用 BO 阈值。

对于 H3C—CH3、H2C—CH2、HC—CH，在相应中性闭壳层假设下，C—C 分别可分配为单键、双键、三键。决定因素包括氢的实际邻接位置和两端完整配位环境。

### CH3 的约束案例

一个 C 连接三个 H 时，三条 C—H 为普通单键，不能通过给 C—H 加双键使碳补满四价。片段若电中性，7 个价电子中 6 个用于三条键，余下一个未配对电子，对应甲基自由基候选 [CH3]。

| 片段电子状态 | 同一连接图的候选解释 |
| --- | --- |
| 总电荷 0 | CH3 自由基 |
| 总电荷 +1 | CH3 正离子 |
| 总电荷 −1 | CH3 负离子 |

ReaxFF 部分电荷 q 不能逐原子四舍五入成形式电荷；体系电中性也不能证明每个片段电中性。电子状态未知时，记录采用的假设及候选，不虚构唯一结论。

### 几何与一致性检查

坐标用于检查键长、局部构型及候选冲突，必须正确处理周期边界。共轭、芳香和共振在分子整体上判断，不能仅凭 BO 接近 1.5 赋芳香键。时间信息用于诊断孤立跳变，不能强制抹平真实结构变化。

首版拟优先验证与当前数据相关的 CHO 体系；其他元素、复杂电子态或超出规则能力的结构仍保留原始图并标记。单一合法候选也只表示规则下得到支持，不是量子化学验证。

## 05 物种身份与关键产物

### F06 结构检查和标识生成

利用 RDKit 等工具检查价态、环和芳香性，核对转换前后的元素数、氢数和邻接关系。工具检查通过不等于结构推断正确。[3]

在明确的氢、电荷、自由基和立体信息规则下生成 canonical SMILES，同时尝试生成 InChI 和 InChIKey。生成失败时保留结构图及原因；SMILES 成功与 InChI 成功分别记录。

拟定状态为 supported、ambiguous、unresolved，并另设标识符生成状态。supported 表示在本次规则及假设下获得支持，不能解释为实验确认；不得在未校准时输出貌似统计概率的置信度。

### 物种归并

用于归并的标识不包含模拟原子 ID；原子映射另存。相同规则下结构一致的不同实例归入同一 species_id。分子式相同不足以归并：乙醇 CCO 与二甲醚 COC 均为 C2H6O，但应区分。

拟以固定规则和版本下的 canonical SMILES 为结构索引，保留 InChI 辅助匹配。共振、互变异构、质子化状态、立体异构和不确定候选的归并政策需单独确认。不得仅用 InChIKey 覆盖结构状态层；标识不一致时进入诊断。

缓存键必须包含影响结构推断的键类型、电子状态假设、标准化策略和版本；仅按原子集合或无键类型连接图缓存，可能错误复用不同结构。

### F07 关键产物匹配

关键产物清单可在分析前配置。程序先按统一规则识别全部分子，再匹配目标，不能只寻找目标而丢失其他前体。

| 目标类型 | 匹配依据 | 结果解释 |
| --- | --- | --- |
| 分子式产物池 | 元素组成 | 例如 C6H6O3，不能直接命名为 HMF |
| 具体结构 | 经确认的目标结构与统一标准化规则 | 例如甲基自由基 [CH3] 或指定 HMF 结构 |
| 结构类别 | 结构片段或明确的分类规则 | 例如含指定呋喃环特征的产物 |

目标可重叠，同一实例命中多个类别时需注明；汇总类别之和不能自动当作总分子数。对存在歧义的结构输出候选命中，不计入具体结构的 supported 命中数。元素组成可靠时仍可进入相应分子式池。

记录 target_id、命中规则、实例 ID、species_id、时间、原子集合及匹配状态。目标清单和结构标准化规则必须随运行保存，允许后续基于保留的数据重做匹配。

## 06 候选反应事件识别

### F08 原子映射与事件分组

比较相邻有效帧的连接集合：旧帧有而新帧无的连接记为断键，新帧有而旧帧无的连接记为成键。已确认的化学键类型变化另外记录。电子状态推断改变与真实连接变化须分字段保存，不直接混算。

构建前后帧分子之间的对应图：两帧分子共享原子 ID 时建立关联。对相互关联且结构发生变化的分子分组形成候选事件，保留所有参与者和计量系数。同一大型分子内多个变化可能被合成一个粗粒度事件，应标记，后续再研究细分方法。

### 原子追踪示例

| 时刻 | 分子实例与原子组成 |
| --- | --- |
| 变化前 | CH4 为 C1 H2 H3 H4 H5；OH 为 O6 H7 |
| 变化后 | CH3 为 C1 H2 H3 H4；H2O 为 O6 H7 H5 |

对应变化为断 C1—H5、成 O6—H5，候选反应为 CH4 + OH → CH3 + H2O。氢 H5 的对应关系为事件提供证据；仅观察数量变化不足以建立此原子路径。自由基标注依赖上一步电子状态判定。

### 时间与守恒约束

事件时间记录为前后保存帧构成的区间，不能宣称精确发生在后一帧。0.2 ps 间隔内可能包含多步反应，因此输出称为观察到的候选净结构变化，不自动标为基元反应。

事件前后应核查原子 ID 与元素多重集合守恒。若存在模拟中显式插入、删除原子或不完整输入，应分段或按边界事件处理，不能凭空归成化学反应。缺失帧之间的长跨度变化应标记或禁用默认事件识别。

### 原子交换与不确定结构

反应前后物种类别相同但原子发生交换时，物种级净变化可能为零；原子级事件仍应保留。不得通过过早消去两侧相同物种丢掉交换或催化参与证据。

若分子连接变化可靠但 SMILES 不确定，保留原子级事件与候选身份。候选不确定性向反应汇总和路径传播；不将其与具体已支持结构的计数混合。

每个事件至少保存 event_id、前后帧、时间区间、反应物与产物实例、结构变化、原子映射、诊断和筛选状态。

## 07 往返标记与事件筛选

### F09 保留原始事件

原始候选事件不可因过滤永久删除。筛选结果以独立状态、规则版本和原因记录，允许对同一原始事件集应用不同窗口并重新汇总。事件过滤不隐式重写原始逐帧物种数量。

### 短时往返判据

在配置窗口内追踪同一批原子。只有相关事件链的原子连接及可判定的结构状态恢复到起点，才标记为往返候选。反应式互为正逆但属于不同原子组时，不得相互抵消。

| 类型 | 示例 | 拟定处理 |
| --- | --- | --- |
| 两步返回 | A → B → A | 检查原子与结构恢复后标记 |
| 多步返回 | A → B → C → A | 检查完整相关事件链后标记 |
| 短暂中间体 | A → B → C | 不因 B 只出现一帧就按往返删除 |
| 信息不足 | 接近轨迹边界或后续帧缺失 | 标记边界不足，不当作已证实无往返 |

链的检查范围须包含参与的全部原子与对外连接。若与其他事件耦合，先保证原子闭合和证据完整，再决定是否分组。重叠往返组的消歧、窗口锚点和部分组过滤策略均需确定并测试。

为使首版比较可复现，拟用“起始参考帧至恢复帧”的保存时间跨度定义窗口；例如 0.0、0.2、0.4 ps 的 A、B、A，观察返回跨度为 0.4 ps，不据此声称 B 的精确寿命。

### 科学解释边界

短时恢复可能来自识别波动，也可能是真实正逆过程。因此标签为“符合所设往返规则”，不直接称为假反应。时间稳定性过滤可参考既有工具，但本项目窗口需独立验证。[5]

0.2 ps 的保存间隔不能支持更细时间分辨率的观察。只出现一个保存帧不等于寿命恰为 0.2 ps；首末帧持续存在的分子还存在观察边界问题。

### 拟定默认行为

初版先保留全部候选并输出往返标记，再比较不同窗口下的反应数、关键产物和路径变化。正式默认窗口待敏感性验证后决定。连接层滞后与事件层过滤应联合评估，避免重复过滤过强。

筛选字段至少包含 selection_status、filter_reason、filter_group、filter_policy_id。原始事件计数、筛选后计数和未决计数分别提供。

## 08 反应网络与观察路径

### F10 反应汇总

以 species_id 和计量系数定义反应物、产物多重集合，聚合同类事件；原子 ID 不用于反应类别归并，但通过 event_id 保留。正向与逆向分别记录，必要时归入同一 reversible_group。

例如正向 3 次、逆向 1 次，可报告净事件次数 2。该数值不是速率常数或路径概率；比较时必须使用相同筛选规则。2H → H2 的计量系数不得因集合去重而丢失。

网络采用物种节点与反应节点或等价超边表示，保留共同反应物、产物和系数。原子交换而物种净变化为零的事件保留在明细中，网络是否显示为自循环由显式选项控制。

### F11 关键产物生成路径

以目标产物的具体生成实例为起点，定位其生成事件，再根据原子 ID 找到前体及更早事件。观察路径必须满足时间顺序和原子来源对应，允许分支与汇合。

仅在汇总网络中连通的路线称为“网络候选路线”，不得与观察路径混用。多个时间点重复看到同一产物，不得自动计为多次生成。

| 模式 | 追踪含义 |
| --- | --- |
| 完整原子来源 | 追踪目标中的 C、H、O 等原子来源，保留相关共同反应物 |
| 目标碳来源 | 追踪最终进入目标产物的碳原子经历的结构，仍可回查完整事件 |

路径停止于初始帧、记录缺口、未决身份或配置的深度和时间边界，需逐条记录原因。完整原子追踪允许在身份不确定处继续追踪连接证据，同时保留该节点歧义。

### 路径归并与排序

先形成实例级路径，再依据物种、计量关系、事件顺序和分支结构进行归并。去除模拟原子编号不能破坏所选追踪模式的原子流向关系。共振表示和结构假设不同的路径如何合并需服从统一物种规则。

优先报告“该路径类型对应的目标生成事件数”和目标分子实例数，并说明同一生成事件是否属于多个路径类型。不能把各反应边次数相乘作为路径概率，也不能声称最高次数路径就是唯一机理。

### 路径 SVG

SVG 应展示物种或结构、反应方向、必要的共同参与物、观察次数及歧义标记，并携带对应路径或事件 ID。不绘制未经观察证据支持的机制箭头；布局与交互编辑细节后续定义。

## 09 核心输出与数据关系

以下文件名和字段为拟定数据契约。CSV 用于可比较的行记录，复杂原子映射与分支关系用 JSONL 或 JSON；大数据实例索引的最终存储格式在性能验证后确定。

### 输出一 物种清单

species_registry.csv：每条记录代表一个物种或显式未决结构类别。

字段包括 species_id、formula、canonical_smiles、inchi、inchikey、formal_charge、radical_info、identity_status、identifier_status、assumption_id 和 message。多候选结构放入 identity_candidates.jsonl，并由 candidate_set_id 关联；不能把未决候选伪装成多个已观察分子。

### 输出二 物种数量时间序列

species_timeseries.csv：每条记录包含 frame_id、timestep、time_ps、species_id、count 和统计视图。建议采用长表，并声明零值省略策略和有效帧清单；缺失帧不等于零数量。

以逐帧识别结果为基础输出，事件往返筛选不改变原始数量。若增加时间平滑或重新分配身份的视图，应独立命名并记录算法来源。

### 输出三 物种统计摘要

species_summary.csv：输出初始数量、末帧数量、最大同时数量、出现帧数、有效统计帧数、出现帧比例、逐帧数量累加值。生成与消耗分子数按事件及计量系数计算，区分原始、筛选和未决视图。

### 输出四 反应事件明细

reaction_events.jsonl 为完整记录；reaction_events.csv 为便于查看的平面摘要。每条包含 event_id、时间区间、前后帧、反应物与产物实例、断键成键、键类型变化、原子映射、身份诊断及过滤标记。两种文件的 event_id 必须一致。

### 输出五 反应汇总与网络

reaction_summary.csv 包含 reaction_id、反应物与产物系数、方向或正逆组、原始次数、筛选次数及时间范围。reaction_network.json 保存物种节点、反应节点和计量关系。事件到反应类别的索引另存，避免重复复制大量明细。

### 输出六 关键产物生成路径

target_matches.csv 保存逐实例命中；target_pathways.jsonl 保存生成实例、事件链、原子来源、模式、停止原因和不确定性；pathway_summary.csv 汇总路径类型及观察次数。路径 SVG 与路径 ID 一一关联。

### 追溯支撑记录

需要保留 molecule_instances 及实例内部图的可检索记录，至少能从 frame_id 与 instance_id 获取原子集合和结构来源。仅输出 species_id 数量无法支撑原子追踪。run_manifest.json、frame_index 和 diagnostics 记录配置、帧定位及异常。

关系链为 run_id → frame_id → instance_id → species_id；event_id 连接前后实例；reaction_id 聚合事件；path_id 引用事件链。ID 应在一次运行内唯一并稳定，不要求不同配置运行间盲目复用。

## 10 指标定义与计算边界

以五个有效保存帧中某物种数量依次为 0、1、1、1、0 为例。下列指标必须分列，不能使用一个“累计数量”字段混合表达。

| 指标 | 定义 | 示例或边界 |
| --- | --- | --- |
| 当前帧数量 | 该帧归入物种的实例数 | 0、1、1、1、0 |
| 最大同时数量 | 全部有效帧数量最大值 | 1 |
| 出现帧数 | 数量大于零的有效帧数 | 3 |
| 出现帧比例 | 出现帧数除以有效统计帧数 | 3／5，等于 60% |
| 逐帧数量累加值 | 对有效帧数量求和 | 3 分子·帧 |
| 生成分子数 | 生成事件中该物种产物系数累计 | 需查事件，不能由出现帧数代替 |
| 消耗分子数 | 消耗事件中该物种反应物系数累计 | 分别报告原始与筛选视图 |

若三帧里的实例是同一分子，则可能只发生一次生成。即使每帧数量相同，也可能存在分子同时生成和消耗，必须用原子实例和事件区分。初始存在量不计入模拟期间生成量。

“逐帧数量累加值”是采样依赖量，不是独立分子总数、产率或时间积分。不同保存频率的数据不能直接比较此值。出现帧比例描述被分析轨迹的采样情况，不解释为一般反应概率。

### 身份和筛选口径

分子式池、具体结构物种及结构类别分别统计，重叠目标不重复解释为互斥总量。身份歧义、转换失败、未知组成各有独立标记；只有组成可信的未决结构才能进入相应分子式池。

原始事件和原始数量在完整、封闭、同口径条件下可做收支检查。过滤后事件不能自动要求与未修改的逐帧数量严格收支一致，必须先说明过滤语义。物种级两侧相同但原子交换的事件保留 gross 参与记录，净数量变化单独计算。

### 暂不作最终定义的指标

精确分子寿命需要持续身份规则和边界处理；仅能先记录观察帧区间。产率、选择性需要明确分母、原子来源及计量基准。路径概率需要定义样本空间和归属规则。以上均不由首版基础字段自动冒充生成。

### 输出格式与运行记录

记录编码、缺失值表示、单位、schema_version 和零值策略。嵌套结构不使用无法解析的任意拼接文本。run_manifest 保存输入指纹或校验策略、文件大小、映射、时间配置、阈值、过滤方案、结构标准化规则、依赖版本、运行状态与诊断摘要。

### 流式处理

不一次性读取全部原始轨迹。解析器逐帧提供数据，连接状态与事件检测保留必要上下文；时间窗口受配置约束。长期原子路径和实例数据应写入可检索存储，不能为了后续追踪把全部帧常驻内存。

缓存按唯一结构及完整推断条件使用，设置容量或落盘策略。窗口大小、唯一物种数量和路径分支都可能影响内存，禁止只宣称“流式所以恒定内存”。当前不承诺未经基准测定的秒级速度或固定内存上限。

### 失败与复现

失败或中断输出须标为 incomplete，不冒充完整网络。复算或未来续算必须校验配置与输入身份；不同参数结果分别保存，不覆盖原始文件。断点续算、存储后端及路径规模限制列为待决技术项。

### 分阶段交付

第一阶段验证输入、连接与分子实例；第二阶段验证结构身份、关键产物和事件；第三阶段完成筛选、网络、路径及输出契约；最后运行真实数据与敏感性验收。每阶段交付可运行内核和证据，再进入下一阶段，不以页面开发替代算法验收。
